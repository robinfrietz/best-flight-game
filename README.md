Sky Runner is a pseudo-3D chase-view flight game: pilot your plane over rolling green terrain with a river, a small town and a runway below, thread the golden rings for points, and dodge the snow-capped mountains and towers — with a lit cockpit panel showing ALT, SPD and HDG, levels that keep speeding up, and full keyboard + mouse control.

## Run it

```sh
node serve.ts
```
